# Roadmap — Retired

> **This roadmap has been retired.** The project is now governed by the
> **[Project Charter](../PROJECT_CHARTER.md)** (adopted 2026-07-02, v4.2.0),
> which defines the purpose, the nine-workflow Acceptance Contract that gates
> releases, a zero-obligation candidate list, and a permanent won't-do list.
>
> The open-ended goals previously tracked here (80% coverage, Phase 3 IDE
> enhancements, Phase 4 scale-out) were either moved to the charter's candidate
> list (Jedi autocomplete, linting/format-on-save) or explicitly declared
> won't-do. See the charter §6 and §7 for the disposition of every item.
>
> Historical phase documents remain in [archive/](archive/) for reference.
